#Simple Calculator

This project is a basic calculator built using HTML, CSS, and JavaScript. It performs standard arithmetic operations and demonstrates simple UI design along with DOM-based JavaScript functionality.

Features :
Supports addition, subtraction, multiplication, and division
Clean and minimal user interface
Hover and active button effects
Basic error handling for invalid expressions

Project Structure :
index.html     → Calculator layout  
style1.css     → Styling and layout  
index1.js      → JavaScript logic  

How to Use:
Open the index.html file in any web browser to use the calculator.
